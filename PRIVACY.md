# Política de Privacidad de Del Camionero

**Última actualización: 7 de septiembre de 2026**

**Del Camionero** es una herramienta para camioneros orientada a organizar el camión, calcular costos y rentabilidad, compartir viajes o cargas y solicitar ayuda comunitaria. La aplicación busca recolectar únicamente los datos necesarios para prestar esas funciones.

## 1. Datos del camión, mantenimiento, documentos y cálculos

Los datos ingresados en Mi Camión, mantenimiento, documentación, consumos, viajes y calculadoras se almacenan principalmente de forma local en el dispositivo. Del Camionero no exige una cuenta personal visible para usar esas herramientas.

## 2. Compartir viaje y cargas

Cuando el usuario decide publicar espacio disponible o una carga para compartir, Del Camionero procesa los datos que el propio usuario ingresa, como origen, destino, fecha estimada, capacidad, tipo de vehículo, WhatsApp de contacto, notas y, cuando corresponda, valor del flete y comisión.

Estas publicaciones se almacenan en Firebase y pueden ser consultadas por otros usuarios autenticados técnicamente en la aplicación que busquen coincidencias de ruta. El número de WhatsApp informado queda visible en la publicación para permitir el contacto. El usuario puede marcar una publicación como resuelta, tras lo cual deja de mostrarse como activa.

## 3. Ubicación, Modo En Ruta y SOS Comunitario

La ubicación se utiliza únicamente cuando el usuario activa una función que la necesita. En funciones comunitarias puede procesarse temporalmente la ubicación junto con datos de ruta para identificar usuarios cercanos o distribuir un aviso de ayuda.

- La aplicación no realiza seguimiento permanente de ubicación cuando las funciones que la requieren no están activas.
- Las presencias comunitarias se identifican mediante un usuario técnico anónimo y están diseñadas para ser temporales.
- Al enviar un SOS se procesa la categoría, ubicación, ruta y momento del aviso para distribuir la alerta a usuarios cercanos.

## 4. Notificaciones

Del Camionero puede solicitar permiso para enviar notificaciones relacionadas con alertas comunitarias. Para ello se utiliza un identificador técnico anónimo y un token de notificaciones. La aplicación no requiere nombre, DNI ni una cuenta pública para esta función.

## 5. Servicios de terceros

La aplicación puede utilizar Google Firebase para autenticación técnica anónima, almacenamiento de publicaciones y datos comunitarios, funciones en la nube y notificaciones. Para cálculos de ruta puede utilizar servicios de Google o, como respaldo, OpenStreetMap/Nominatim y OSRM. También puede abrir Google Maps, WhatsApp u otros servicios externos cuando el usuario lo solicita. Esos proveedores procesan información conforme a sus propias políticas.

## 6. Precio de combustible y datos de configuración

La aplicación puede descargar una configuración pública con precios de combustible y otros parámetros operativos. Esa información no identifica al usuario. Los cálculos de combustible y rentabilidad se realizan a partir de los datos ingresados por el usuario y de esa configuración.

## 7. Publicidad, venta de datos y analítica

Del Camionero no vende datos personales. La versión actual no incorpora una plataforma propia de seguimiento publicitario ni analítica de comportamiento destinada a crear perfiles comerciales del usuario.

## 8. Permisos

En Android, la aplicación puede solicitar acceso a Internet, ubicación y notificaciones. Los permisos sensibles se solicitan cuando una función los necesita y pueden revocarse desde los ajustes del dispositivo.

## 9. Conservación y seguridad

Los datos locales permanecen en el dispositivo hasta que el usuario los modifica, borra sus datos desde la aplicación, Android elimina los datos de la aplicación o desinstala la aplicación. Las publicaciones y datos comunitarios almacenados en Firebase se conservan durante el tiempo necesario para operar las funciones, gestionar publicaciones resueltas, seguridad y mantenimiento del servicio.

## 10. Borrado de datos

Del Camionero incluye la opción **Privacidad y datos > Borrar mis datos**. Esa acción elimina los datos locales de la aplicación y, cuando exista una identidad técnica anónima activa, intenta eliminar las publicaciones y datos comunitarios asociados a esa instalación antes de borrar dicha identidad.

Las instrucciones públicas para borrar datos también están disponibles en:

https://github.com/Sebas00012/Del-camionero-precios/blob/main/DELETE_DATA.md

## 11. Responsabilidad del usuario al publicar

El usuario debe evitar publicar información sensible que no sea necesaria para coordinar un viaje o una carga. La información que el usuario decide compartir voluntariamente, como su WhatsApp, puede ser vista por otros usuarios de Del Camionero dentro de la función correspondiente.

## 12. Cambios a esta política

Esta política puede actualizarse cuando cambien las funciones, los proveedores utilizados o los requisitos legales. La fecha de actualización se mostrará en esta página.

## 13. Contacto

Para consultas sobre privacidad, el usuario puede utilizar el correo de contacto del desarrollador publicado en la ficha oficial de Del Camionero en Google Play.
